출처: # 고영향 인공지능 해당 여부 확인 요청 — 요청 안내 · ## 핵심 내용
키워드: 고영향 AI 해당 여부, 확인 요청 창구, 인공지능기본법 제33조, 판단 가이드라인, 안내데스크

## 핵심 내용
- 인공지능기본법 제33조에 따라, 인공지능사업자가 고영향 AI 해당 여부의 확인을 요청하는 온라인 창구입니다.
- 먼저 사업자가 스스로 검토하고, 그래도 추가 확인이 필요할 때만 요청하라고 안내합니다.
- 스스로 판단할 때는 '고영향 인공지능 판단 가이드라인'을 먼저 보라고 안내합니다.
  - 가이드라인 안내: https://www.sw.or.kr/AI_act_helpdesk (링크는 페이지에 적힌 주소이며, 직접 열어 보지는 않았습니다 — **확인 필요**)
- 일반적인 판단 기준을 상담하는 안내데스크도 함께 안내합니다.
